# Slime manhwa: chapters

Page images for the webtoon "Chto? Teper ya slizy?" (What? I'm a slime now?), chapters 1-10.
Each folder `chNN/` holds the pages `p01.jpg`, `p02.jpg`, ... in reading order and a `manifest.json`.
The pages are hosted here so the chapters can be embedded in Telegraph articles.

Reader: https://neoxider.github.io/slime-manhwa-chapters/ (dark background, no gaps between parts, remembers the scroll position).
